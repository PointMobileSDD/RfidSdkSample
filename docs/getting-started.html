Point Mobile SDK

SDK Installation Guide

Point Mobile SDKs are distributed through a private Maven repository. This guide shows how to add one to your Android project with the access token you get from the Point Mobile portal. For API details, see each SDK's reference.

Installation

Available SDKs

Add each SDK with a single dependency declaration. Find the SDK you need below and use its dependency in step 3.

SDKDependencyReference

Install from the Maven repository

Access to the private repository requires an access token from the Point Mobile portal. Follow these three steps to configure it.

Step 1: Add your access token
Open local.properties in your project's root directory (the file containing sdk.dir) and add your token as shown below. Android Studio's default .gitignore excludes this file from version control. On a build server, set the ORG_GRADLE_PROJECT_pointmobileMavenToken environment variable instead.

local.propertiesProperties
# Add your token below the existing sdk.dir line.
pointmobileMavenToken=<your token>

Step 2: Add the repository to settings.gradle.kts or settings.gradle
Place the token lookup code above the dependencyResolutionManagement block and the maven { … } block inside its repositories block. With Kotlin DSL, also add the import at the top of the file. The code reads the token from local.properties first, then checks the Gradle property of the same name. If neither contains a token, Gradle sync stops with a missing-token error.

settings.gradle(.kts) 
// Add this import at the top of the file.
import java.util.Properties

// Your existing pluginManagement { … } and plugins { … } blocks stay above this.

// Reads the token from local.properties, or from the Gradle property of the same name.
// On a build server, set the ORG_GRADLE_PROJECT_pointmobileMavenToken environment variable.
val localProperties = Properties().apply {
    val file = settingsDir.resolve("local.properties")
    if (file.isFile) file.inputStream().use { load(it) }
}
val pointmobileMavenToken: String =
    (localProperties.getProperty("pointmobileMavenToken")
        ?: providers.gradleProperty("pointmobileMavenToken").orNull)
        ?.trim()?.takeIf { it.isNotEmpty() }
        ?: throw GradleException("Add pointmobileMavenToken=<your token> to local.properties.")

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        // Add the Point Mobile Maven repository, using the token read above.
        maven {
            url = uri("https://raw.githubusercontent.com/PointMobileSDD/maven/master")
            credentials(HttpHeaderCredentials::class.java) {
                name = "Authorization"
                value = "token $pointmobileMavenToken"
            }
            authentication { create<HttpHeaderAuthentication>("header") }
        }
    }
}
// Your existing pluginManagement { … } and plugins { … } blocks stay above this.

// Reads the token from local.properties, or from the Gradle property of the same name.
// On a build server, set the ORG_GRADLE_PROJECT_pointmobileMavenToken environment variable.
def localProperties = new Properties()
def localFile = new File(rootDir, 'local.properties')
if (localFile.isFile()) localFile.withInputStream { localProperties.load(it) }
def pointmobileMavenToken = (localProperties.getProperty('pointmobileMavenToken')
        ?: providers.gradleProperty('pointmobileMavenToken').getOrNull())?.trim()
if (!pointmobileMavenToken) {
    throw new GradleException('Add pointmobileMavenToken=<your token> to local.properties.')
}

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        // Add the Point Mobile Maven repository, using the token read above.
        maven {
            url = 'https://raw.githubusercontent.com/PointMobileSDD/maven/master'
            credentials(HttpHeaderCredentials) {
                name = 'Authorization'
                value = "token $pointmobileMavenToken"
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
    }
}

Older projects may declare repositories in the root build.gradle under allprojects { repositories { … } }. In that case, add the Groovy code to that file instead: the token lookup above the allprojects block, and the maven { … } block inside its repositories.

Step 3: Add the SDK to app/build.gradle.kts or app/build.gradle
On the next Gradle sync, Gradle downloads the SDK and its dependencies.

app/build.gradle(.kts) 
dependencies {
    // Add the SDK you need. See the table above for its dependency.
    implementation("ex.dev.sdk:rfid:1.2.0")
}
dependencies {
    // Add the SDK you need. See the table above for its dependency.
    implementation 'ex.dev.sdk:rfid:1.2.0'
}

Do not store your token in files tracked by version control. If you store it in a file such as settings.gradle.kts, anyone with access to that file can use the token to download the SDK.

Install from a file

If you downloaded the SDK as a file from the Point Mobile portal, copy it to app/libs/ and add a dependency using its filename.

app/build.gradle(.kts) 
dependencies {
    // Copy the file from the portal into app/libs/ and use its name here.
    implementation(files("libs/ex.dev.sdk.rfid_1.2.0.aar"))
}
dependencies {
    // Copy the file from the portal into app/libs/ and use its name here.
    implementation files('libs/ex.dev.sdk.rfid_1.2.0.aar')
}

Installing the SDK from a file does not automatically add its dependencies. Add the libraries listed in the SDK reference manually. For example, a Java-only app that uses the RFID SDK also needs the Kotlin standard library.

If Gradle sync fails

"Add pointmobileMavenToken=… to local.properties"
Gradle couldn't find your token. Make sure local.properties in your project's root directory has a pointmobileMavenToken line.

"Could not find ex.dev.sdk:…"
This can occur if the repository rejects your token or the requested version does not exist. Check that you copied the entire token, that it has not expired, and that the version matches the table above.
