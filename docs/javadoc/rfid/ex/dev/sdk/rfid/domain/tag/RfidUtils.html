      • calculatePC

        @NonNull() static String calculatePC(@Nullable() String writeData, boolean umi, boolean xi, boolean toggle, @Nullable() String attributeOrAfi)

        Builds the PC word that has to precede an EPC being written.

        The PC word preceding the EPC specifies its length. If this length does not match the written EPC, the tag may report truncated data or include existing memory contents without reporting an error.

        The length is derived from writeData, so the two cannot disagree.

        Parameters:
        writeData - the EPC about to be written, as hex.
        umi - whether the tag has user memory.
        xi - whether an XPC word follows.
        toggle - false when the tail carries attribute bits, true when it carries an AFI.
        attributeOrAfi - the attribute bits or AFI as a hexadecimal string, depending on toggle.
        Returns:

        the PC word as exactly four uppercase hex digits, or — when an argument is wrong — a longer string of the form "E<n>: <reason>". Check for that before writing it to a tag, and tell the two apart by length, not by the first letter: the PC word of a 28- or 29-word EPC is itself four hex digits starting with E (E000–EFFF). Both fields have fixed widths — the tail holds one byte and the length field counts at most 31 words, 29 with xi — and a value that does not fit comes back as an error rather than silently corrupting the word above it.

      • checkPCLength

         static boolean checkPCLength(@Nullable() String pc, @Nullable() String writeData)

        Checks whether the length declared by a PC word matches the supplied EPC length.

        Use this method to check an independently supplied or manually edited PC word before writing the EPC.

        This compares lengths, it does not validate the EPC. Only pc is parsed; writeData is measured, four characters to a word, whatever those characters are. A caller that needs the EPC checked for hex and whole words does that itself.

        Parameters:
        pc - the PC word as four hex digits, or null.
        writeData - the EPC that follows it, as hex, or null.
        Returns:

        false when the declared length and the measured one disagree, when either argument is missing, or when pc cannot be parsed. Nothing is logged — the return value is the only signal.
