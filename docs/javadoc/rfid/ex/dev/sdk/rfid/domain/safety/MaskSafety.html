Package ex.dev.sdk.rfid.domain.safety

Object MaskSafety

  • All Implemented Interfaces:
    
public class MaskSafety

    Validation helpers for checking whether a masked operation selects the intended tag.

    A masked access runs a Gen2 Select and then acts on the selected tags. Several Select actions do not select the matching tag: under action 4 the matching tag is deselected and every other tag is selected, so a masked kill would destroy every tag in the field except the intended one, and the reader would report success.

    Readers: RF88 · MF52. The SDK does not check this — a masked command goes out under whatever Select is in force, and the reader acts on the tags it selects. Use these helpers to check the settings before a masked write, lock or kill, or to tell an operator what is wrong with them.

    The required arguments depend on the reader. The Select target requirement applies only to the MF52. Pass RfidManager.getAction() for either reader, and add RfidManager.getTarget() only when the MF52 is the one connected — passing the RF88's target reports its ordinary configuration as unsafe.

      • actsOnMatchingTag

        @JvmOverloads() final static Boolean actsOnMatchingTag(String action, String target)

        Whether a masked operation run with this Select configuration acts on the matching tag.

        Pass what RfidManager.getAction() returns, not null. Null is read as the reader default — the ordinary select, which is safe — but on the MF52 the action is kept for the whole device, so another app may have left an inverting one in force. An empty string, which the getter returns when it could not read the value, is reported unsafe.

        Parameters:
        action - the Select action in force, as RfidManager.getAction() returns it.
        target - the Select target, on the MF52 only.
